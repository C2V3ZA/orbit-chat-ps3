# Orbit Chat 0.9.5 für PS3

Text- und Sprachchat von PS3 zu PS3. Kein Konto, kein Passwort, keine Router-Einstellungen.

## Loslegen

1. Orbit starten, Namen bestätigen.
2. KREUZ: Gruppe erstellen. DREIECK: Freund einladen (20-Zeichen-Code).
3. Freund: QUADRAT drücken, Code eintippen. Fertig.
4. SELECT: Sprachchat beitreten / auflegen. R2: Mikrofon stumm / an.

## Übers Internet ohne Router-Einstellungen

Orbit nutzt einen kleinen eigenen Vermittler-Server. Beide PS3 verbinden sich von innen nach außen,
deshalb muss an keinem Router etwas freigegeben werden. Alles bleibt Ende-zu-Ende verschlüsselt.

Die Adresse des Vermittlers trägt nur EINE Person einmal ein: Menü > Verbindung & Status > DREIECK.
Wer eingeladen wird, bekommt die Adresse automatisch mit dem Einladungscode.

## Tasten

Steuerkreuz: Gruppe · KREUZ: Schreiben · SELECT: Sprachchat · R2: Stumm · DREIECK: Einladen ·
QUADRAT: Code eingeben · KREIS: Menü · L1/R1: Blättern · R3: FPS · START: Beenden

PS-Taste: Das XMB öffnet sich über Orbit, Chat und Sprachchat laufen darunter weiter.
